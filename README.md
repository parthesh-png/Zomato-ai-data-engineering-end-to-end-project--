In this project, I identified a problem where a food delivery company had a large volume of order and customer review data, but the data was difficult to use for business analysis because it was coming from raw sources and required significant processing before it could provide useful insights.

I validated the problem by looking at the different types of information the company needed, such as order performance, customer behavior, and review sentiment. I then built an end-to-end data pipeline using AWS S3, Snowflake, dbt, and Airflow to clean, transform, test, and organize the data into usable layers. I also added an AI layer using OpenAI for review enrichment, RAG-based review analysis, and natural-language SQL queries. This showed that the problem was worth solving because the processed data could be used for both reliable analytics and AI-powered business insights.
